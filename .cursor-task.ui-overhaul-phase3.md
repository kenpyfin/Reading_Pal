## Objectives

1. Show Signpost (`purpose`) as a subtle tag under the card title, not a labeled field block.
2. Show Read along (`thought_process`) as a clickable thread with accent markers. The selected step is emphasized; the text is unchanged.
3. Show Carry forward (`takeaway`) as a high-contrast callout.
4. Keep Author Shortcut and Outsider Guide in collapsed drawers at the bottom of the card, including generate and regenerate actions.
5. Add a compact progress cluster: existing count and bar, a Current button that jumps to the first incomplete top-level card, and one dot per top-level card. The card nearest the top of the guide scroller is marked active.

## Out of scope

- Prompt text, API fields, and card schema stay as they are.
- Phase 4 split-pane and navigation chrome are not part of this phase.
