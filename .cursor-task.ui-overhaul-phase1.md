## 1. Objectives

1. **Install Core Design System Dependencies**:
   - `@radix-ui/themes` (v3.x)
   - `@radix-ui/react-icons`
2. **Wire Theme Provider**:
   - Import `@radix-ui/themes/styles.css` in `frontend/src/index.js` or `frontend/src/theme.css`.
   - Wrap `<App>` root in `<Theme>` from `@radix-ui/themes`:
     - `accentColor="blue"`
     - `grayColor="slate"`
     - `radius="medium"`
     - `scaling="95%"` (compact reading density)
     - `appearance`: dynamic mapping to `effectiveTheme` (`light` / `dark`; sepia mapped cleanly to light with sepia container override).
3. **Harmonize Token Architecture (`theme.css`)**:
   - Map Radix Themes tokens with Reading Pal's semantic `--color-*` variables so existing CSS and new Radix components share unified colors and contrast.
   - Ensure zero regressions for light, dark, and sepia modes.
4. **Establish Typographic Hierarchy**:
   - **Long-form Reading Pane (`.book-pane-body`, `.book-pane`)**:
     - Font size: `1.125rem` (18px)
     - Line height: `1.7`
     - Readable measure: `max-width: 72ch; margin: 0 auto;` (or container class for comfortable reading column).
     - Heading & blockquote proportions tuned for distraction-free reading.
   - **Side / Utility Panes (`.reading-guide-pane`, `.note-pane`)**:
     - Font size: `13px–14px` (`0.8125rem`–`0.875rem`)
     - Line height: `1.45–1.5`
     - High density, utilitarian hierarchy for scannability.
5. **Verification**:
   - Clean production build via `npm run build`.
   - Update `DEVELOPMENT_JOURNAL.md` per repo rules.

## 2. Implementation Steps

### Step 1: Install packages
In `frontend/`:
```bash
npm install @radix-ui/themes @radix-ui/react-icons
```

### Step 2: Global Styles & Provider
1. Import `@radix-ui/themes/styles.css` in `frontend/src/index.js` (before `App`).
2. In `frontend/src/App.js`:
   - Import `{ Theme } from '@radix-ui/themes';`
   - Map `effectiveTheme`:
     ```js
     const radixAppearance = effectiveTheme === 'dark' ? 'dark' : 'light';
     ```
   - Wrap the outer div `.App` with `<Theme accentColor="blue" grayColor="slate" radius="medium" scaling="95%" appearance={radixAppearance}>`.
   - For `sepia` mode, keep `data-theme="sepia"` on `document.documentElement` with custom color overrides preserving sepia background and text colors.

### Step 3: Typography & Measure Tuning
1. In `frontend/src/pages/BookView.css`:
   - Update `.book-pane` and `.book-pane-body`:
     - Standardize body reading typography: `font-size: 1.125rem; line-height: 1.7;`
     - Introduce `.book-content-measure` or set `.book-pane p, .book-pane h1, .book-pane h2, .book-pane h3, .book-pane ul, .book-pane ol, .book-pane blockquote, .book-pane table`:
       - `max-width: 72ch;`
       - Ensure centered layout or natural readable margin.
2. In `frontend/src/components/ReadingGuidePane.css` & `frontend/src/components/NotePane.css`:
   - Ensure utilitarian font sizing remains compact (13-14px) and doesn't inherit accidental 18px body font.

### Step 4: Verification
1. Run `npm run build` in `frontend/` and ensure compilation passes.
2. Verify light, dark, and sepia appearance.
3. Append entry to `DEVELOPMENT_JOURNAL.md`.
