# Task: Integrate Knowledge Mapping Framework into Reading Pal

## 1. Goal
Implement a hierarchical knowledge mapping system for markdown books and use it to enhance the reading guide generation.

## 2. Technical Context
- **KnowledgeMapper**: Located in `backend/services/knowledge_mapper.py`. It currently has functions to extract headings and references.
- **ReadingGuide Models**: Located in `backend/models/reading_guide.py`. We use `ReadingGuide` and `ReadingGuideItem` for book-level roadmaps.
- **LLM Service**: Located in `backend/services/llm_service.py`. This is where guide generation logic lives.
- **API Routes**: `backend/api/books.py` handles the requests.

## 3. Implementation Steps

### Step 3.1: Enhance KnowledgeMapper Service
- Refactor `backend/services/knowledge_mapper.py` into a robust `KnowledgeMapper` class.
- Add a method `to_reading_guide_items(markdown_text: str) -> List[ReadingGuideItem]` that:
    - Generates the hierarchical map.
    - Maps `snippet` to `preview_text`.
    - Maps `purpose` (if generated) to `takeaway`.
    - Includes `hub_score` and `references` (maybe store references in `thought_process` or a new field).
- Implement a method to use the LLM to generate "Signposts" (purpose) for each node if missing.

### Step 3.2: Update ReadingGuide Models
- In `backend/models/reading_guide.py`:
    - Add `hub_score: Optional[int] = 0` to `ReadingGuideItem`.
    - Add `purpose: Optional[str] = None` to `ReadingGuideItem`.
    - Ensure `ReadingGuideItem.model_rebuild()` is called (it is).

### Step 3.3: Integrate into LLM Service
- In `backend/services/llm_service.py`:
    - Add a method `generate_roadmap(markdown_text: str) -> List[ReadingGuideItem]` that uses `KnowledgeMapper`.
    - Update the guide generation logic to use the roadmap as a "Semantic Backbone".

### Step 3.4: API Integration
- In `backend/api/books.py`:
    - Update the `generate_reading_guide` endpoint (if it exists, or create/update it) to call the new roadmap generation.

## 4. Verification Plan
- Create a test script `tests/test_knowledge_mapping.py`.
- Verify that a sample markdown book results in a hierarchical JSON structure.
- Verify that nodes have `hub_score` > 0 when internal references exist.
- Verify that the API returns the roadmap in the `items` list.

## 5. Constraints
- Do not break existing page-specific guide functionality.
- Ensure all Pydantic models remain compatible with MongoDB (handling ObjectIds).
