# Reading Pal 6: Reading Guide Option A — Signpost / Read along / Carry forward

**Status:** Approved / Implementing  
**Decision:** Option A — thread-first card, slim takeaway, stop generating summary/bullets  
**Branch:** continue on `feat/articulation-reading-guide-prompts` (or cut `feat/reading-guide-option-a` from it)  
**Repo:** `/home/ken/big_storage/projects/reading_pal_6`

## Goal

Stop the card body from competing as a third summary. Each always-visible block has one job:

| UI label | Field | Job | Length |
|---|---|---|---|
| **Signpost** | `purpose` | Why this pillar exists in the book’s arc | 1–2 sentences |
| **Read along** | `thought_process` | Author’s moves in order (primary guide) | 3–5 steps |
| **Carry forward** | `takeaway` | Residue only — what sticks after reading | 2–3 sentences max |

Depth modes stay collapsed: Author Shortcut / Outsider Guide.

## Non-goals (this pass)

- No DB migration / field deletion from `ReadingGuideItem`
- No regen of all existing guides automatically
- No changes to Architect (segmentation) pass thresholds
- No changes to Author Shortcut / Outsider Guide generation logic beyond card-context text if needed

## Phase 1 — Mentor Pass prompts (`llm_service.py`)

File: `backend/services/llm_service.py` → `_build_semantic_reading_guide_items` (card_system + card_user)

### 1.1 Rewrite field roles (orthogonal tests)

Replace the current five-field “substance dump” roles with:

1. **purpose (Signpost)** — answers *Why am I here?* Arc only. No claims list, no how-to-read.
2. **thought_process (Read along)** — answers *What do I track as I read?* 3–5 steps; each step is a **verb/move** (“opens with…”, “complicates with…”, “pays off by…”). Optional craft hint may trail a step after an em dash; steps are not mini-summaries of conclusions.
3. **takeaway (Carry forward)** — answers *What do I keep when I leave?* **2–3 sentences max**. Compression of residue already earned in the thread — not a new dump. No claim that isn’t already earned in a thread step.
4. **quote** — verbatim craft anchor (unchanged intent).

### 1.2 Stop generating summary/bullets

- Remove `reading_summary` and `reading_bullets` from the Mentor Pass JSON schema in `card_user`.
- Fallback `card_data` when LLM fails: omit those keys (or set empty / null); do not fabricate a summary from the source excerpt.
- Parsing: keep reading existing `reading_summary` / `reading_bullets` if an old model returns them, but **do not require** them; prefer writing `None` / empty for new cards so UI hides the blocks.
- Update `_custom_angle_prompt_block(..., for_segmentation=False)` to mention `purpose`, `thought_process`, `takeaway` only (drop summary/bullets wording).

### 1.3 Anti-duplication rules (hard prompt constraints)

Add explicit rules:

- Do not repeat the same noun phrase / claim across purpose, thought_process, and takeaway.
- Thread steps = moves, not restated conclusions.
- Takeaway = compression of the thread’s payoff, not a retell.
- Forbidden: filling takeaway with 4–6 exhaustive substance sentences (that role moves to Author Shortcut).

### 1.4 Soften “standalone knowledge unit” pressure on the card body

Current card_system says the card must leave the reader with “full substance” without opening the original. That fights Option A (full substance lives in Author Shortcut / Outsider Guide).

Revise to:

- Card body = orientation + read-along + residue.
- Full articulation / knowledge-surrogate depth = Author Shortcut / Outsider Guide (on demand).
- Still: ground every sentence in SOURCE TEXT; preserve authorship; no boilerplate.

### 1.5 Card chat context

In `chat_roadmap_card`, rebuild `card_context` around Signpost / Read along / Carry forward. If legacy `reading_summary` / `reading_bullets` exist on old cards, include them under a “Legacy fields” line only when non-empty — do not treat them as required.

## Success checks

On a regenerated long pillar:

1. Card body shows only Signpost → Read along → Carry forward (no How to read / Summary / Quick points).
2. Takeaway is visibly shorter than the thread (≤ ~3 sentences).
3. No near-duplicate sentences across the three blocks.
4. Thread steps read as moves, not a second summary.
5. Old cards without regen still load (null/empty summary/bullets simply absent).
6. Author Shortcut / Outsider Guide still generate and render collapsed.
7. No mid-sentence truncation regressions (existing token-budget hotfix remains).
