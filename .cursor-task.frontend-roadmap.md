# Implementation Spec: Frontend Roadmap UI (Signposts & Hubs)

Update the Reading Guide UI to utilize the new `hub_score` and `purpose` (Signpost) fields from the Knowledge Mapping backend.

## 1. Components

### RoadmapCard (frontend/src/components/ReadingGuidePane.js)
- Destructure `hub_score` and `purpose` from `item`.
- **Signpost**: Render `item.purpose` right below the section title if it exists.
  - Class: `roadmap-signpost`
- **Hub Badge**: If `item.hub_score > 0`, render a badge next to the title.
  - Class: `roadmap-hub-badge`
  - Content: `Knowledge Hub (${item.hub_score})` or similar.

## 2. Styling (frontend/src/components/ReadingGuidePane.css)

### .roadmap-hub-badge
- Background: `#fff3cd` (light yellow) or `#e2e3e5`.
- Border: `1px solid #ffeeba`.
- Color: `#856404`.
- Padding: `2px 6px`.
- Border-radius: `12px`.
- Font-size: `0.75em`.
- Font-weight: `bold`.
- Margin-left: `8px`.

### .roadmap-signpost
- Margin: `4px 0 10px 0`.
- Font-style: `italic`.
- Color: `#5a6268`.
- Font-size: `0.9em`.
- Border-left: `2px solid #dee2e6`.
- Padding-left: `10px`.

### General Refinement
- Ensure the hierarchy is visually distinct.
- Improve the spacing between roadmap cards.

## 3. Implementation
Use `cursor_agent` to apply these changes.
